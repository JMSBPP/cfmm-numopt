**gdxdiff — the return-code table is richer than the roadmap's, and the 3-argument form is a trap.**
Measured with `gdxdiff` from GAMS 54.1:
- 2-argument form `gdxdiff A B`: **rc=0** identical ("No differences found"), **rc=1** different.
- **rc=2** no arguments. **rc=3** a named input file is missing.
- **rc=7** when the third (output) argument names a path gdxdiff cannot rename its temp file to —
  e.g. a different filesystem. **In that state rc=7 is returned for identical AND for different

```make
# ── GATE-05: fixture freshness, scoped to what payoff-fixtures can produce ──
# gdxdiff is used in its TWO-ARGUMENT form and run with cwd inside the scratch
# directory. Measured: the 3-argument form returns rc=7 for identical AND for
# different inputs when it cannot rename its temp file to the given output path,
# and gdxdiff drops `diffile.gdx` into the current directory either way.
# Predicate: rc != 0. See model/test/README-gdxdiff.md for the full rc table.
FIXTURE_DIR        ?= $(GAMS_DIR)
CHECK_FIXTURES_TSV ?= model/fixtures/FIXTURES.tsv
FIXTURE_SCRATCH    := $(GAMS_DIR)/$(GAMS_BUILD)/fixtures

.PHONY: check-fixtures

check-fixtures:
	@set -e; rm -rf $(FIXTURE_SCRATCH); mkdir -p $(FIXTURE_SCRATCH); \
	names=$$(awk -F'\t' '!/^#/ && NF {print $$1}' $(CHECK_FIXTURES_TSV)); \
	if [ -z "$$names" ]; then \
		printf 'check-fixtures FAIL: no fixtures declared in %s\n' "$(CHECK_FIXTURES_TSV)"; \
		exit 1; \
	fi; \
	for n in $$names; do \
		cp "$(GAMS_DIR)/$$n" "$(FIXTURE_SCRATCH)/wt_$$n"; \
		cp "$(FIXTURE_DIR)/$$n" "$(FIXTURE_SCRATCH)/ref_$$n"; \
	done; \
	$(MAKE) payoff-fixtures; \
	for n in $$names; do \
		cp "$(GAMS_DIR)/$$n" "$(FIXTURE_SCRATCH)/new_$$n"; \
		cp "$(FIXTURE_SCRATCH)/wt_$$n" "$(GAMS_DIR)/$$n"; \
	done; \
	rc=0; \
	cd $(FIXTURE_SCRATCH); \
	for n in $$names; do \
		if gdxdiff "ref_$$n" "new_$$n" > "diff_$$n.log" 2>&1; then \
			printf '   FRESH  %s\n' "$$n"; \
		else \
			printf '   STALE  %s  (gdxdiff rc != 0 -- see %s/diff_%s.log)\n' "$$n" "$(FIXTURE_SCRATCH)" "$$n"; \
			rc=1; \
		fi; \
	done; \
	printf '\ncheck-fixtures: compared %s fixture(s)\n' "$$(printf '%s\n' $$names | wc -l)"; \
	exit $$rc
```

**1. Write `model/test/lean_sorry_check.py`** with the CLI
`lean_sorry_check.py <lean-file> <declaration-id>` and the exit contract already published by the
shell wrapper: `0` found and clean, `1` found and contains `sorry`/`admit`, `2` not found,
`3` usage/file error. Implementation requirements:

- **Namespace tracking.** Maintain a stack from lines matching `^\s*namespace\s+(\S+)` and pop on
  `^\s*end\s+(\S+)` when the name matches the top of the stack. A declaration's fully-qualified
  name is `".".join(stack + [name])`.
- **Declaration matching.** A declaration line matches
  `^(?P<indent>\s*)(?:@\[[^\]]*\]\s*)?(?:private\s+|protected\s+|nonrec\s+|noncomputable\s+)*(?P<kw>theorem|lemma|def|abbrev|instance|example)\s+(?P<name>[^\s({\[:]+)`.
  The requested id matches if it equals `name` **or** equals the fully-qualified name. Matching is
  exact — no prefix matching, because a prefix match is how a rename goes undetected.
- **Body extent.** From the declaration line to (exclusive) the next line whose indentation is
  **less than or equal to** the declaration's indentation and which itself begins a new construct:
  `^\s*(?:@\[|private\s|protected\s|nonrec\s|noncomputable\s|theorem\s|lemma\s|def\s|abbrev\s|instance\s|example\s|structure\s|inductive\s|namespace\s|end\b|section\b|open\s|import\s|/-)`.
  Otherwise EOF. **This is the defect being fixed**: the previous `awk` terminated only on
  column-0 constructs, so a later `sorry` could be attributed to an earlier declaration.
- **Comment stripping before the scan**, in this order: remove `/- ... -/` blocks non-greedily
  across newlines (this removes the `sorry` in backticks at `eta.lean:602`); then drop everything
  from `--` to end of line. Only then search for `\bsorry\b` or `\badmit\b`.
- On success print `lean-sorry-check OK: <file>::<qualified-name> (<n> lines, no sorry/admit)`.
  On failure print the offending line number and text to stderr.
